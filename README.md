# SmileQuest — Milestone 1
1. `npm install`
2. Create a Supabase project; run `supabase/migrations/0001_foundation.sql` in the SQL editor.
3. `cp .env.example .env.local` and fill in URL + anon key.
4. `npm run dev` (use HTTPS, e.g. a tunnel or Vercel preview, for camera work in later milestones).
Auth: enable Email provider; add your site URL to Supabase redirect allow-list.
